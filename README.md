# Project IRIS — EOG Eye Movement Classification

## Overview

This project aims to develop a baseline machine learning model capable of recognizing eye movements from Electrooculography (EOG) signals.

EOG measures electrical potential differences generated by eye movements, providing a non-invasive method for tracking eye activity. By applying signal processing, feature extraction, and machine learning techniques, this project investigates how EOG signals can be classified into distinct eye-movement categories.

The long-term goal is to explore EOG-based human-computer interaction (HCI), particularly its potential for assistive communication systems that allow users to interact with computers through intentional eye movements.

## Project Objectives

- Develop a baseline machine learning model for EOG-based eye movement classification.
- Identify suitable datasets containing labeled eye-movement signals.
- Preprocess raw EOG recordings to reduce noise and artifacts.
- Extract meaningful features that distinguish different eye movements.
- Train and evaluate classification algorithms, starting with Random Forest.
- Investigate the feasibility of translating recognized eye movements into computer commands.

## Target Eye Movements

The initial classification model aims to recognize the following movements:

| Eye Movement | Description |
|---|---|
| Left | Eyes move toward the left |
| Right | Eyes move toward the right |
| Blink | Brief closure and reopening of the eyelids |
| Neutral | No intentional directional movement or blink |

Additional classes, such as upward and downward movements or double blinks, may be explored depending on dataset availability.

## Methodology

The proposed machine learning pipeline consists of the following stages.

### 1. Dataset Selection

Identify publicly available EOG datasets containing labeled eye movements, particularly left, right, blink, and neutral events.

Datasets will be evaluated based on their sampling frequency, signal quality, number of participants, annotation quality, and availability of relevant movement classes.

### 2. Signal Preprocessing

Apply appropriate preprocessing techniques to improve EOG signal quality.

Potential methods include:
- Low-pass or band-pass filtering
- Baseline drift correction
- Artifact detection and handling
- Signal normalization when appropriate

Preprocessing methods will be selected based on the characteristics of the chosen dataset.

### 3. Window Segmentation

Divide continuous EOG recordings into fixed-length or event-centered windows for classification.

Window size and overlap will be selected experimentally to capture relevant eye-movement patterns while minimizing classification latency.

### 4. Feature Extraction

Extract statistical and temporal features from each EOG window, including:

- Mean
- Standard deviation
- Minimum and maximum amplitudes
- Signal range
- Root mean square (RMS)
- Mean absolute difference
- Net signal change

Additional features may be explored to better capture eye-movement direction, amplitude, duration, and blink characteristics.

### 5. Machine Learning Classification

Develop a baseline classifier using the **Random Forest** algorithm.

Random Forest combines multiple decision trees trained on sampled data and feature subsets. Each tree predicts an eye-movement class, and the ensemble combines these predictions to determine the final classification.

Additional models may be investigated for performance comparison.

### 6. Model Evaluation

Evaluate classification performance using:

- Accuracy
- Confusion matrix
- Precision
- Recall
- F1-score

Where possible, training and testing will be separated by recording session or participant to assess model generalization and reduce data leakage.

## Current Progress

**Phase 1 — Baseline Development**

An initial MATLAB classification pipeline has been implemented using an EOG office-activity recognition dataset.

The existing implementation includes:
- Loading and visualizing EOG recordings
- Identifying annotation transitions
- Segmenting signals into 1-second windows
- Extracting 16 statistical features from two EOG channels
- Training a Random Forest classifier with 100 decision trees
- Evaluating predictions using accuracy and a confusion matrix

The initial dataset is designed for office-activity recognition rather than direct eye-movement classification. It is being used to establish and test the machine learning pipeline.

**The next step is to identify a suitable dataset with explicit eye-movement labels and adapt the existing model to classify left, right, blink, and neutral movements.**

## Long-Term Application

The long-term vision is to support assistive communication through eye-movement-based computer interaction.

For example, recognized movements could be mapped to interface commands:

| Detected Movement | Potential Computer Command |
|---|---|
| Look Left | Move selection left |
| Look Right | Move selection right |
| Blink / Double Blink | Confirm selection |
| Neutral | No action |

These mappings are potential future applications and are not yet implemented in the baseline classifier.
